# ASD-STE100 writing

Write all output in ASD-STE100 only. See skills/operator/asd-ste100/SKILL.md.

This skill is the writing rule for all factory agents and all operator skills.

## When to use

Use this skill when you write factory text or stakeholder text.
Use it for Jira cards.
Use it for behaviour cards.
Use it for SME briefs.
Use it for comments.
Use it for paste blocks.

## Recipe

Write short sentences.
Write one idea in each sentence.
Use approved verbs.
Use the active voice.
Do not use contractions.
You may use technical names. Examples: REST, SQL, HTTP, file paths.
Where the STE dictionary is silent, use British spelling. Examples: behaviour, organisation.

## Stakeholder artefacts

Name the owner of the work.
Do not write "foreman".
Write full sentences.
Keep grades of the form X/10 as they are.

## Refuse

Do not write factory or stakeholder text in informal English.
Do not use contractions in output.
Do not replace a named owner with "foreman".
Do not change a grade of the form X/10.
